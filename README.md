# Self-Driving-Car-Reinforcement-Learning-System
CARLA is an open-source autonomous driving simulator that I am using as a research and development platform to design, train, and evaluate self-driving systems in realistic virtual environments. It provides high-quality urban maps, vehicles, and infrastructure assets along with flexible configuration of sensors such as cameras, LiDAR, RADAR, and GPS, enabling testing under diverse traffic, weather, and lighting conditions. The platform supports integration with ROS and learning-based approaches like imitation learning and reinforcement learning, making it suitable for benchmarking, experimentation, and validation of end-to-end autonomous driving pipelines in a safe and controlled simulation setup.
